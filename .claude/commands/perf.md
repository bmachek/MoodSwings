Hand this to the `perf-scout` subagent: $ARGUMENTS

The protocol is not optional, because this repository has already reported both
"eleven percent slower" and "twelve percent faster" about the same change:
`--release`, `--frames 200` (the default window times a half-built scene), two or
three runs, and both commits built back to back and shot in the same minute — a
before/after half an hour apart is measuring the fan.

If the spread is as large as the difference, the answer is "no measurable
change", not a direction. On a software rasteriser or with no GPU, it reports
that and gives an algorithmic reading of the diff instead of a figure.
